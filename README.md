👻 Mystery Haunting

**Mystery Haunting** is a uniquely crafted, fully animated, spooky, haunted portfolio theme designed to evoke intrigue and immerse visitors in a mysterious, spooky experience. The design showcases a haunted house silhouette, enigmatic navigation, atmospheric visual details, playful animated elements, and a fun paranormal vibe. It features nine themed pages — from a haunted foyer landing page to a séance-style contact form — all wrapped in a gothic aesthetic with ghost-teal glows, pumpkin accents, and atmospheric effects.
